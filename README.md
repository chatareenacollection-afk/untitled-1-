# A-R Styles — Contemporary Eastern Couture, Luxury Watches & Accessories

A full-stack, production-ready luxury fashion boutique and horology web application built with React 19, TypeScript, Tailwind CSS, and Express.

---

## Features

- **Storefront & Collections**: Contemporary ready-to-wear pret, unstitched 3-piece suites, bridal couture, luxury timepieces & watches, and statement jewelry.
- **Dynamic Real-Time SEO (ReactHelmet)**: Automatic title, meta tags, OpenGraph, Twitter Cards, and Schema.org JSON-LD microdata updates per product and category.
- **Persistent Backend Storage**: Live persistent product, category, orders, and customer management with multi-device background synchronization.
- **Executive Boutique Management Portal**: Access via secret passkey (`Gujjarfamily19109$$Gujjarfamily19109$$`) or by tapping the header crest logo.
  - Image uploading with drag-and-drop & gallery picker.
  - Live order tracking and dispatch status updates.
  - Email notification gateways (Resend, SendGrid, Gmail SMTP).
- **Responsive & Mobile-First**: Crafted with high-contrast typography, warm neutral palette, and drawer navigation.

## Quick Start

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/your-username/a-r-styles.git
cd a-r-styles
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Production Build & Start
```bash
npm run build
npm run start
```

---

## Environment Configuration

Create a `.env` file based on `.env.example`:
```env
PORT=3000
NODE_ENV=production
```
